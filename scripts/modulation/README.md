# Modulation Scripts Directory

This directory contains modular scripts that provide specific functionality components for the Panacea ecosystem.

## Available Modules

- **service-orchestrator.js** - Main service orchestration and coordination
- **api-modulator.js** - API endpoint modulation and management  
- **database-modulator.js** - Database connection and configuration modulation
- **wallet-modulator.js** - Multi-chain wallet service modulation
- **ai-modulator.js** - AI service integration and modulation
- **telegram-modulator.js** - Telegram bot service modulation
- **deployment-modulator.js** - Deployment service coordination

## Usage

Each modulator can be used independently or as part of the integrated ecosystem.

```bash
# Run individual modulators
node scripts/modulation/api-modulator.js
node scripts/modulation/wallet-modulator.js

# Run service orchestrator
node scripts/modulation/service-orchestrator.js
```
